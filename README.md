# Analyze Student Marks Dataset

## Project Description

This project analyzes a student marks dataset using Python.

## Objective

The main objective is to learn:

- Pandas
- NumPy
- Basic data cleaning
- Data analysis

## Dataset

The dataset contains information such as:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## Tasks Performed

1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Cleaned missing numerical data.
4. Calculated average scores.
5. Calculated maximum scores.
6. Calculated minimum scores.
7. Displayed the results.
8. Saved the cleaned dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- VS Code
